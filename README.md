# Caytori - Centralized IT Support Management System

Caytori is a modern, unified IT support management platform designed for enterprise helpdesk operations, incident triage, asset lifecycle tracking, and proactive system health monitoring.

## Features

- **Centralized Helpdesk Queue:** Ingest and manage tickets across hardware, software, network, and security domains.
- **Interactive Ticket Triage:** Real-time search, priority filtering, and instant incident logging modal.
- **IT Asset Lifecycle Tracking:** Monitor laptops, workstations, peripherals, and network gateways.
- **Proactive Infrastructure Status:** Real-time uptime monitoring for SSO, Active Directory, and VPN nodes.
- **Self-Service Knowledge Base:** Provide employees with instant access to troubleshooting guides and security guidelines.

## Quick Start

Open `index.html` directly in any standard browser or serve using a local server:

```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
